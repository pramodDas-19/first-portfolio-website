# Portfolio Website (First Project)

> 🚀 My first website built from scratch while learning front-end web development.

## 📖 About

This project is my very first portfolio website and the first complete website I developed using HTML, CSS, and JavaScript.

Although it is a simple single-page application, it represents the beginning of my journey into web development. Building this project helped me understand the fundamentals of creating responsive web pages, organizing layouts, styling components, and adding basic interactivity.

I have kept this repository on GitHub as a milestone to showcase my growth as a developer.
